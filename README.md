# LUXORA — GitHub Pages এ ফ্রি লাইভ করার নিয়ম

এই ফোল্ডারে তোমার প্রজেক্টের রেডি বিল্ড ফাইল আছে। GitHub Pages ব্যবহার করে সম্পূর্ণ ফ্রি-তে লাইভ লিংক বানানো যাবে — কোনো কোডিং লাগবে না।

## ধাপ ১: GitHub-এ নতুন repository বানাও
1. https://github.com এ লগইন করো (না থাকলে ফ্রি অ্যাকাউন্ট বানাও)
2. উপরে ডানে **+** বাটনে ক্লিক করে **New repository** দাও
3. নাম দাও যেমন: `luxora-preview`
4. **Public** সিলেক্ট করো (Pages ফ্রি হতে হলে Public হতে হবে, unless তোমার GitHub Pro আছে)
5. **Create repository** ক্লিক করো

## ধাপ ২: এই ফাইলগুলো আপলোড করো
1. নতুন repo পেজে **"uploading an existing file"** লিংকে ক্লিক করো
2. এই ফোল্ডারের ভেতরের **সব ফাইল ও ফোল্ডার** (index.html, 404.html, .nojekyll, asset-manifest.json, static/ সব) ড্র্যাগ করে ছেড়ে দাও
   - ⚠️ পুরো ফোল্ডার আপলোড কোরো না — ফোল্ডারের **ভেতরের জিনিসগুলো** সরাসরি repo-র root-এ থাকতে হবে
3. নিচে **Commit changes** ক্লিক করো

## ধাপ ৩: GitHub Pages চালু করো
1. repo-র **Settings** ট্যাবে যাও
2. বাম পাশের মেনুতে **Pages** এ ক্লিক করো
3. **Source** এর নিচে সিলেক্ট করো: **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)** সিলেক্ট করে **Save** দাও
5. ১-২ মিনিট অপেক্ষা করো — উপরে একটা লিংক দেখাবে যেমন:
   `https://tomar-username.github.io/luxora-preview/`

## ব্যস, রেডি! 🎉
এই লিংকটাই এখন তোমার লাইভ প্রিভিউ — এটা তোমার বন্ধুর সাথে শেয়ার করো, ও যেকোনো ব্রাউজার থেকে দেখতে পারবে।

---

### নোট
- এই বিল্ডটা একটা React app-এর (SPA), তাই `404.html` ফাইলটা রাখা জরুরি — এটা রাউটিং ঠিকভাবে কাজ করার জন্য।
- ভবিষ্যতে যদি নতুন ভার্সন লাইভ করতে চাও, শুধু নতুন বিল্ড ফাইলগুলো দিয়ে পুরনোগুলো replace (overwrite) করে আবার commit করলেই হবে — Pages অটো আপডেট হয়ে যাবে।
- চাইলে GitHub এর বদলে Netlify বা Vercel-এ এই একই ফোল্ডার ড্র্যাগ-ড্রপ করেও সেকেন্ডে লাইভ করা যায় (drag-and-drop deploy) — যদি আরো সহজ অপশন লাগে বলো।
